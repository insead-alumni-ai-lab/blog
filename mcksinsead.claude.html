How McKinsead works

Four steps from context
to communication.

01
Load your company context

Upload financial statements, strategy documents, and reports. Set industry, geographies, revenue band, and strategic challenges. McKinsead indexes your documents in Qdrant for hybrid RAG retrieval throughout the analysis.

02
Enrich with live intelligence

Before any framework runs, the enrichment agent pulls live macroeconomic indicators, sector dynamics, competitor moves, and geopolitical risk scores — partitioned and injected into the frameworks that need them.

03
Execute the framework sequence

The LangGraph orchestrator enforces the dependency DAG. Each output is self-critiqued before flowing downstream. Human review checkpoints are mandatory at SWOT synthesis and hypothesis tree approval — you are always in control.

04
Generate your narrative and slides

The synthesis agent identifies cross-framework convergences and contradictions. The narrative agent applies the Pyramid Principle. The slide agent produces a self-contained HTML deck — insight-first titles, pre-rendered SVG charts, speaker notes included.

FAQ

Frequent questions.

If the answer is not here, write to us and we will add it.

Is my company data used to train the model?
No. All API calls include the anthropic-beta: fine-tuning-off header. Your documents, session results, and company data are never used to train Anthropic's models. Company knowledge is stored in a tenant-isolated Qdrant collection and is deleted when you close your account.
Can I supply my own Anthropic API key?
Yes, on the Professional plan and above. Your key is stored encrypted (AES-256-GCM) in our database — it is never logged, never passed through SSE payloads, and never visible after initial entry. LLM costs are then billed directly to your Anthropic account, not marked up by McKinsead.
How long does a complete strategy session take to run?
A full 12-framework session with enrichment, hypothesis tree, and narrative typically takes 18–35 minutes end-to-end. Enrichment and frameworks run concurrently where possible. The mandatory human review checkpoints add time proportional to how much you choose to amend — the system waits for your input before proceeding downstream.
What happens if an enrichment data source is unavailable?
Individual source failures are soft-handled — they are logged and the affected enrichment signal is marked as UNAVAILABLE, but the workflow continues with whatever context is available. Framework results that rely on the missing signal annotate their claims with a data-availability warning. Partial enrichment is always preferable to a blocked analysis.
How does MECE validation work for the hypothesis tree?
At each sibling level of the tree, two checks run automatically. For mutual exclusivity, hypothesis labels are embedded and pairwise cosine similarity is computed — pairs above a tunable threshold (default 0.72) are flagged as potential overlaps. For collective exhaustivity, a second LLM pass asks whether the sibling set jointly covers the parent hypothesis without gaps. Both results appear in a MECE report card on each tree node and are surfaced at the human review checkpoint.
Can multiple team members work on the same session?
Yes, on the Professional plan. Sessions support owner, editor, and viewer roles within an organisation. Concurrent edits use optimistic locking via ETag headers — if two editors modify the same framework result simultaneously, the second write returns a 412 Precondition Failed response and the user is asked to review and resubmit. Annotations and inline comments are available for async collaboration.
Can I export the analysis in formats other than HTML?
The HTML export is self-contained, offline-capable, and renders cleanly in any modern browser. PDF export is available via headless-Chrome rendering (Chromium is required on your machine or our infrastructure does it server-side). PPTX export and a full JSON data export of all framework results are on the roadmap for Q3 2026.
